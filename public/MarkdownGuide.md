# Markdown 语法说明书

欢迎使用 Markdown！这是一份简洁的语法指南，帮助你快速掌握 Markdown 的常用语法。

---

## 1. 标题

使用 `#` 号来创建标题，一个 `#` 是一级标题，两个 `##` 是二级标题，以此类推。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

---

## 2. 文本样式

### 粗体
用两个 `**` 或 `__` 包围文本：

```markdown
**这是粗体文本**
```

### 斜体
用一个 `*` 或 `_` 包围文本：

```markdown
*这是斜体文本*
```

### 删除线
用两个 `~~` 包围文本：

```markdown
~~这是删除线文本~~
```

### 行内代码
用反引号包围代码：

```markdown
这是 `行内代码` 示例
```

---

## 3. 列表

### 无序列表
使用 `-`、`*` 或 `+` 加空格：

```markdown
- 项目一
- 项目二
  - 子项目
- 项目三
```

### 有序列表
使用数字加点号：

```markdown
1. 第一项
2. 第二项
3. 第三项
```

### 任务列表
使用 `- [ ]` 或 `- [x]`：

```markdown
- [ ] 未完成任务
- [x] 已完成任务
```

---

## 4. 链接和图片

### 链接
使用 `[文字](链接地址)`：

```markdown
[点击访问示例网站](https://example.com)
```

### 图片
使用 `![替代文字](图片链接)`：

```markdown
![示例图片](https://via.placeholder.com/150)
```

---

## 5. 引用

使用 `>` 加空格：

```markdown
> 这是一段引用文本。
> 可以多行书写。
```

---

## 6. 代码块

使用三个反引号，并指定语言：

````markdown
```javascript
function hello() {
  console.log("Hello, World!");
}
```
````

---

## 7. 表格

使用竖线 `|` 和连字符 `-`：

```markdown
| 列1 | 列2 | 列3 |
| --- | --- | --- |
| 内容1 | 内容2 | 内容3 |
```

---

## 8. 分割线

使用三个或更多的 `-`、`*` 或 `_`：

```markdown
---
```
